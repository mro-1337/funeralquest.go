FUNERAL QUEST 1.8.2 - HELP
==============================================================================
Funeral Quest by Seth A. Robinson, ported to Go. One program (fq) runs the BBS
door, the web game, the telnet and RLogin servers and the network link between
towns; fqedit is the full-screen sysop editor.

Where to read more:
  QUICK-INSTALL.md   up and running in ten minutes
  README.md          the full manual
  CHANGES.md         what's new in each version
  docs\              the same three as web pages (open them in any browser)
  extras\rlogin\     RLogin setups for Synchronet, Mystic and SyncTERM

PROGRAMS
------------------------------------------------------------------------------
  Windows 64-bit   fq.exe          fqedit.exe
  Windows 32-bit   fq32.exe        fqedit32.exe     (32-bit BBS software too)
  Windows ARM      fq-arm64.exe    fqedit-arm64.exe
  Linux x86-64     fq-linux        fqedit-linux
  Linux 32-bit     fq-linux32      fqedit-linux32
  Linux ARM64      fq-linux-arm64  fqedit-linux-arm64  (Raspberry Pi 64-bit)
  Linux ARM        fq-linux-arm    fqedit-linux-arm    (Raspberry Pi 32-bit)
  macOS / BSD      build from the source archive with ./build.sh

FIRST STEPS
------------------------------------------------------------------------------
  1. fq.exe version                  check it runs
  2. fq.exe web --port 8080           start the web game
  3. open http://localhost:8080/sysop/ and enter the ADMIN SETUP CODE shown
     in the fq web window (also in data\server.log and
     data\sysop-setup-code.txt), then choose the admin password
  4. set the town name and rules under Settings (or run fqedit.exe)
  5. BBS door command line:  fq32.exe door %f   (Synchronet; see README)
  6. link to another town: admin Network tab, or  fq.exe admin link host:port
     (one link joins a whole network: towns introduce each other)

COMMANDS
------------------------------------------------------------------------------
Funeral Quest

  fq door <DOOR32.SYS or node dir> [--stdio] [--bbs-id NAME] [--nosound]
  fq web [--port 8080] [--host 0.0.0.0] [--cert FILE --key FILE] [--trust-proxy]
  fq telnet [--port 2323] [--net-port 8081]      also runs the network link
  fq net [--port 8081]                          only the network link (door-only BBSes)
  fq rlogin [--port 1513]                       only the RLogin server (plus the network link)
  (fq telnet also takes RLogin callers when the rlogin_port setting or --rlogin-port is set)

  fq admin players | config [key=value ...] | maint | backup | backups | reset [--wipe] | delete <name> | news <text>
  fq admin sysop-password [password]        turn on the web sysop pages (/sysop)
  fq admin bans | ban <ip> [minutes] | unban <ip>
  fq admin links | link <address:port> | accept <id> | unlink <id> | block-link <id>
  fq admin test-link <address:port>         check the way to another town step by step
  fq admin id                               show this server's version, network ID and fingerprint
  fq admin use-theirs <town> [setting ...]  copy a linked town's game settings (all differing ones if none named)
  fq admin propose                          ask every linked town to switch to this town's game settings
  fq admin votes | vote <id> yes|no         settings votes
  fq admin make-cert [host ...]             make a self-signed HTTPS certificate (and use it)
  fq admin cert | https-off                 show the certificate / go back to plain HTTP
  fq version                                show the version

  The full-screen editor is the separate program fqedit.

  --home DIR   folder with assets/, gamedata/, web/ and data/ (default: the exe's folder)

FILES
------------------------------------------------------------------------------
  data\world.json            the whole game, settings included (back up data)
  data\server.log            web/network log     data\door.log   door log
  data\security.log          bans, failed log-ons, admin changes
  data\blocklist_ip.txt      blocked IPs/ranges  data\blocklist_hosts.txt
  data\allowlist_ip.txt      never blocked (put your own address here)
  data\tempbans.json         temporary bans
  data\net\                  network link (identity.json = this town's key)
  data\tls\                  self-signed HTTPS certificate, if made
  gamedata\*.txt             game texts (edit in fqedit or the web admin)

TROUBLE?
------------------------------------------------------------------------------
  Can't link to another town:  fq.exe admin test-link their.host:port
  Behind Caddy or a proxy:     set a Network port and tick "Linked servers
                               use the network port only" (README: Caddy)
  Locked yourself out:          fq.exe admin unban <ip>, then add your IP to
                               data\allowlist_ip.txt
  Forgot the admin password:    fq.exe admin sysop-password
  Pictures don't show:          see "The JPEG XL check" in README.md
